# AQA Combined Science Paper 1 Higher

A simple website linking to AQA GCSE Combined Science: Trilogy (8464) Paper 1 Higher question papers and mark schemes for Biology, Chemistry and Physics.

## Exam series included
- June 2025, June 2024, June 2023, June 2022
- November 2021, November 2020

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will provide the published site URL when deployment completes.

PDF files are hosted by AQA; this repository contains the website, not copies of the exam papers.
